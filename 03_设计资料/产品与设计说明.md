# 02 · 产品与设计｜要做什么

这里解释要做什么、为什么做、页面应该长什么样，不放可运行代码。

如果你是老板，最值得看的不是技术计划，而是产品规格和设计规范。

| 目录 | 用途 |
| --- | --- |
| 规格与计划/specs | 产品规格、3.0 规划、范围和门控 |
| 规格与计划/plans | 具体设计/实现计划 |
| 设计规范 | 颜色、字体、布局、圆角、响应式和动效原则 |

如果你要判断“这个功能为什么要做、用户怎么用”，看这里。
如果你要打开可点击的 HTML 原型，去 [05_网站程序（电脑使用）](../05_网站程序（电脑使用）/老板查看说明.md)。

这里不放任务进度、老板决策、截图证据、程序源码和依赖包。做决定后，结果写回 02_项目管理。
