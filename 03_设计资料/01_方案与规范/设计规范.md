# 云文档 · E「空间工作台」设计锚点

## 1. 视觉主题与气质

- 这是桌面端企业知识工作台，不是 AI 营销页。界面应像一张安静、精密、可以直接操作的银白工作桌。
- 记忆点是“连续三段产品框架 + 白色内容画布 + 底部任务输入器”：产品导航关系保持稳定，内容占主位，装饰主动退后。
- 三拨盘锁定：变化度 6、动效 4、信息密度 7。保留清晰的空间层级，但不以大片留白牺牲效率。
- 功能契约：用户 3 秒内能辨认当前模块、当前范围和主动作；在新建任务页能立即选择模式、资料与技能并提交目标。

## 2. 色彩与角色

- 外部空间：`#F5F5F7`，只承担画布间距与层级。
- 主内容面：`#FFFFFF`。
- 一级文字：`#1D1D1F`；二级文字：`#6E6E73`；三级文字：`#86868B`。
- 唯一交互蓝：`#0071E3`；浅选中面：`#EAF3FF`；禁止紫蓝渐变与第二套品牌强调色。
- 结构线：`rgba(0, 0, 0, .08)`；静态卡片优先靠背景差异，不堆阴影。
- 成功、警告、危险色仅用于真实状态，不能参与装饰。

## 3. 字体与排版

- 中文使用系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- 正文 14px / 1.6；紧凑标签 12–13px；模块标题 18px / 1.4；首页标题 30–34px / 1.16。
- 中文只用 400、500、600；不使用斜体、负字距或装饰中文字体。
- 标题 `text-wrap: balance`，正文 `text-wrap: pretty`，表格数字启用 `tabular-nums`。

## 4. 组件语法

- 全局工具栏：沿用产品既有 68px 宽度，与云文档侧栏连续拼接；选中态使用浅蓝实体面。
- 云文档侧栏：沿用产品既有 272px 宽度，与主工作区连续拼接；导航项 36px 高、8px 圆角。
- 顶部栏：52px 高，无分割线；模块主切换直接占标题位，右侧只放主动作与必要辅助动作。
- 按钮：默认 32px 高、8px 圆角；主按钮使用 `#0071E3`，按压缩放至 `.98`。
- 卡片：统一 10px 圆角；静态卡片无投影，只有可浮动/可拖拽/弹层使用深度。
- 输入器：12px 圆角，顶部输入、底部工具栏和发送按钮同一基线；发送按钮 40px 圆形。
- 文档图标统一为“纸张/页面”轮廓；连接器统一为“链路”语义，禁止分享箭头冒充连接器。

## 5. 布局与间距

- 桌面骨架不可改动：全局工具栏、云文档侧栏、主工作区保持三段式连续布局，三段之间 `gap: 0`，只保留原有 1px 纵向分隔线。
- 三段框架本身禁止做成独立悬浮卡片；空间感只用于主工作区内部，不改变产品级导航关系。
- 基础单位 4px，常用间距 8 / 12 / 16 / 20 / 24px；页面内容默认 16px，禁止无意义的 40px+ 空隙。
- 首页为无外框主任务区 + 264px 线框上下文栏；上下文栏可收至 48px，窄屏收为单列。
- 首页输入器在桌面端与主任务区底边对齐，不在其下保留无功能空白。
- 技能、专家、连接器以三列高密度目录呈现；卡片内部信息对齐，不为每个字段再造容器。
- 表格与长列表优先平面行布局，卡片只用于需要独立点击、比较或承载状态的对象。

## 6. 材质与深度

- 产品级三段框架使用稳定实体面，不通过玻璃、外置圆角或间距制造悬浮关系。
- 弹层/输入器借用 Raycast 的“外环 + 顶部内高光”：`0 0 0 1px rgba(0,0,0,.06), inset 0 1px rgba(255,255,255,.9)`。
- 常规内容卡片不使用大面积投影；浮层投影为冷灰染色的两层柔和阴影。
- 不使用纹理、彩色雾、装饰光斑、玻璃嵌玻璃。

## 7. Do / Don't

- Do：把蓝色只留给可点击和聚焦状态；让标题、范围和主动作形成清楚路径；统一圆角、图标和内边距。
- Do：专家和连接器继续放在“更多”内；技能保留在主导航。
- Do：标题栏与页面通栏保持白底且无硬分割线。
- Don't：不回到卡片墙、胶囊滥用、紫蓝渐变、空泛说明、信任口号或重复标题。
- Don't：不让静态卡片悬浮，不用多套阴影，不用 `transition: all`。

## 8. 响应式规则

- `≤ 1180px`：目录网格 3 列降为 2 列，首页上下文列保持 232px。
- `≤ 760px`：隐藏桌面工具架与侧栏，使用已有移动导航；页面单列；触控目标最少 44px。
- 窄屏输入器工具栏可横向滚动，但发送按钮始终固定在右下角，不被挤走。
- 所有页面禁止横向页面级滚动；超长标题必须省略或换行。

## 9. 动效规则

- 动效只用于反馈与来源关系，时长 120–190ms，统一 `cubic-bezier(.23,1,.32,1)`。
- Hover 仅改变背景、边界、透明度或 `translateY(-1px)`；单页只允许一种签名 hover。
- Press 使用 `scale(.98)`；抽屉按来源方向移动；弹窗从中心 `scale(.96 → 1)`。
- 不使用 `ease-in`、`transition: all`、不可中断关键帧串演。
- `prefers-reduced-motion` 禁止位移与循环动画；`prefers-reduced-transparency` 将所有半透明浮层改为不透明实体面。

## DNA 注入记录

- 从 Apple 借：`#F5F5F7` 外部空间、`#1D1D1F` 主文字、`#0071E3` 唯一交互蓝、8px 标准控件圆角。
- 从 Apple 借：48–52px 紧凑导航高度与 44px 移动触控目标，不借营销页式巨量留白。
- 从 Raycast 借：浮层的外环 + 顶部内高光深度，但只用于输入器和弹层，不作用于三段产品框架。
- 从 Raycast 借：8px 基础节奏与 8–16px 相关组件间距，不借暗色主题和多彩强调色。

## 工艺密度清单

1. 单一蓝色 `::selection`。
2. 品牌化 `:focus-visible` 环。
3. 三段式产品框架的连续边界与稳定纵向分隔。
4. 输入器的外环 + 顶部内高光。
5. 统一的细滚动条。
6. 目录卡片只在 hover 时轻抬 1px 的签名交互。
7. 列表数字使用等宽表格数字。
