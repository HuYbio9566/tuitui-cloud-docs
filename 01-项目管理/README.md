# 01 · 项目管理｜老板工作区

这是推推项目的管理区。这里放项目怎么推进的材料，不放 HTML、前端源码、截图或构建产物。

如果你只想看进度，请直接打开 [项目驾驶舱](00-项目驾驶舱/项目驾驶舱.md)。如果你要做决定，再看下面的任务、需求和决策。

如果你是第一次打开项目，只看 [[00-项目驾驶舱/项目驾驶舱]]；这里的内容都用来回答“为什么做、现在做到哪、接下来做什么、谁确认了什么、哪个版本可以回退”。

产品生命周期主线是：

```text
产品价值 → 用户场景 → 需求路线图 → 知识内容 → 三种 AI 模式
→ 设计与原型 → 实现 → 质量验收 → 版本发布 → 决策复盘
```

## 你在这里能看到什么

- `00-项目驾驶舱`：项目现在的状态。
- `01-产品战略`：为什么做这个产品。
- `02-用户与场景`：谁会用、解决什么问题。
- `03-需求与路线图`：准备做什么、先做什么。
- `05-设计与原型`：页面方案和评审结果。
- `07-质量与验收`：做完以后是否合格。
- `08-版本与发布`：当前版本和可以回退到哪个版本。
- `09-决策与复盘`：已经确认过什么、为什么这么决定。

## 这里不放什么

- 不放 HTML、TypeScript、JavaScript、图片素材原文件。
- 不放程序自动生成的依赖和构建文件。
- 不把“设计稿 v5”写成“产品版本 5”；产品版本和设计编号分开记录。

## 保存确认规则

- 这套结构先建立，不自动导入历史聊天、截图、Eagle 文件或临时资料。
- 发现可能有价值的内容时，先询问：保存什么、保存到哪里、为什么保存。
- 只有得到明确确认后，才复制或移动材料。
- 临时截图默认不保存。
