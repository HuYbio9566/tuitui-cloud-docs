# 项目规则（简版）

1. Codex 项目目录是唯一原文件位置；Obsidian 通过软连接查看同一份文件，不复制第二份。
2. 老板日常只看 `00_老板首页`。项目管理只保留四个入口：总览、任务、版本、历史。
3. 代码、依赖、网页配置和构建文件只放在 `05_网站程序（电脑使用）`，不改成中文，也不随意删除。
4. 产品版本号和设计稿编号分开：产品版本写 `1.2.1`、`1.3.1`；设计稿写 `v5`。
5. 发现聊天、截图、参考文档可能有价值时，先向老板说明保存内容、位置和理由；确认后再复制或移动。
6. 不执行 GitHub push、tag、Release 或 Pages 发布，除非老板单独确认。
