# 底部用户栏改为半透明状态色

## 本次调整

- 将左侧底部用户栏从实心白色背景改为浅蓝紫主题的半透明渐变。
- 增加轻微背景模糊，让用户栏与左侧主题背景自然融合。
- 保留现有信息结构：姓名、消息图标、更多图标。

## 视觉规则

- 渐变：`rgba(232,235,255,.76)` → `rgba(245,242,255,.68)`
- 模糊：`backdrop-filter: blur(10px)`
- 不添加实心白色底、不改变文字和操作入口。
