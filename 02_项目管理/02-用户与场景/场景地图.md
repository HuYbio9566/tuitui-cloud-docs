# 场景地图

## 核心场景

### A · 制度/流程问答

问题 → 权限范围 → 引用答案 → FAQ/文档草稿。

### B · 项目周报任务

目标 → 计划 → 人工确认 → 执行 → 风险/待办 → 周报。

### C · 知识库治理

扫描 → 重复/过期/缺口/公开风险 → 清单 → 逐项确认。
