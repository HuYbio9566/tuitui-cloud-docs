# 产品与流程

## 核心用户旅程

```text
提出问题/目标
→ 选择知识范围与权限
→ 获取答案或任务计划
→ 人工确认关键动作
→ 完成任务/生成文档
→ 沉淀为可复用资产
```

## 页面与状态清单

| 模块 | 正常态 | 异常态 | 结果 |
| --- | --- | --- | --- |
| 找答案 | 有来源回答 | 无来源、权限不足 | 引用答案/FAQ 草稿 |
| 办任务 | 待确认、执行中 | 暂停、失败、部分完成 | 周报/待办 |
| 写文档 | 生成、编辑 | 来源失效、目标无权限 | 文档版本 |
| 知识治理 | 重复、过期、缺口 | 密级风险 | 待复核清单 |
